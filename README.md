## 🔄 Flujo de trabajo

1. **Rama principal**: `main` (protegida)
2. **Ramas de trabajo**: `feature/nombre-sección` para cada cambio
3. **Pull Requests**: Se requiere PR para cualquier cambio en `main`
4. **Publicación**: Al fusionar en `main`, la página se actualiza automáticamente

## 🛠 Cómo colaborar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/rubiod1/retail-core-ht8.git
   cd retail-core-ht8
   ```

2. Crea una rama para tu sección:
   ```bash
   git checkout -b feature/nombre-sección
   ```

3. Edita tu sección en `index.html`

4. Commit y push:
   ```bash
   git add .
   git commit -m "Feat: actualización de sección"
   git push origin feature/nombre-sección
   ```

5. Abre un Pull Request en GitHub
